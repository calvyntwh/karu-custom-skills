# rubber-ducking Review Queue

This file holds open issues, suggested improvements, and TODO items for the skill. Adapted from Etsy debriefing's "action items" workflow and Google's "follow-up actions" pattern.

**Entry template** (one entry per open item):

```
## [YYYY-MM-DD] {Brief title}

**Issue:** What's wrong or unclear.
**Suggested fix:** Concrete change to SKILL.md (or a reference link if it's about behavior, not text).
**Severity:** HIGH (breaks protocol) | MEDIUM (incomplete coverage) | LOW (cosmetic).
**Owner:** Who is responsible (default: next reviewer).
**Status:** open | in-progress | resolved | wontfix.
---
```

**Review cadence:** triage this file when the skill is invoked after a 60+ day gap. Mark resolved items as `[resolved YYYY-MM-DD]` and leave them in place as history.
