# pareto-principle Validated Learnings

This file holds validated, recurring patterns that have proven useful across multiple invocations. Adapted from Google SRE's "what we learned" pattern in post-mortems and Etsy's debriefing artifact model.

**Entry template** (one entry per validated learning):

```
## [YYYY-MM-DD] {Brief title}

**Pattern:** One sentence describing the recurring situation.
**Why it works:** The underlying mechanism (the skill's core principle).
**When to apply:** Trigger conditions that surface this pattern.
**Counter-pattern:** When this pattern does NOT apply (avoid over-generalization).
**Source:** Where the learning came from (CORRECTIONS entry, observation, cited reference).
---
```

**Promotion rule:** a learning graduates here from CORRECTIONS.md after 3+ similar entries.
