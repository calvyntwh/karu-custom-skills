# decision-matrix Promoted Patterns

This file holds patterns that have moved from LEARNINGS to the SKILL.md body. Format mirrors incident.io's "lessons learned → runbook updates" workflow.

**Entry template** (one entry per promoted pattern):

```
## [YYYY-MM-DD] {Brief title}

**Promoted from:** LEARNINGS.md entry (cite the date and title).
**SKILL.md change:** Section heading + paragraph reference, or diff snippet.
**Effective date:** When the change was merged.
**Supersedes:** Previous wording if this replaces an older pattern.
---
```

**Goal:** a one-line entry here should be enough to find what changed in the protocol and why. Long descriptions belong in git commit messages.
